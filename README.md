# HOME

One-page website for HOME, the family ministry of Spring of Life Church. It follows the Spring of Life Church design system, so it looks like the rest of the church's websites.

## Files

- `index.html` is the page (its content, the HOME logo and a few page-specific styles).
- `css/tokens.css` holds the church's colours, type sizes, spacing and corners, in light and dark.
- `css/bundle.css` is the church website's shared component styles (header, footer, buttons, lists).
- `fonts/` has the church fonts (Manrope, and Newsreader Italic).
- `team.jpg` is the team photo.

Keep everything in the same folder structure as `index.html`.

## Put it online with GitHub Pages

1. Open the repository's **Settings** and choose **Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Pick the **main** branch and the **/ (root)** folder, then save.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/` (or at the address in `CNAME`).
